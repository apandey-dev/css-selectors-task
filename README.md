# CSS Selectors Practice

A webpage built to practice different CSS selectors like element, class, ID, and pseudo-classes. It styles headings, paragraphs, links, and lists using an external stylesheet without inline styles.

### Technologies Used
- HTML
- CSS

### Files Included
- `index.html`
- `style.css`
- `README.md`
